# Docs Asset Studio — مستخرج صور المستندات

يستخرج صور ملفات **PowerPoint (.pptx)** و**Word (.docx)** و**Excel (.xlsx)** و**PDF**، يربط كل صورة بموضعها في المستند، يطبّق القص الأصلي (`srcRect`)،
يقص الهوامش، يكشف المكرر بالبصمة البصرية **داخل المستند الواحد وعبر عدة مستندات**، ويتيح التعديل والتصدير — كل شيء محلياً بلا رفع أي ملف.

### عدة ملفات دفعة واحدة
- اختر أو اسحب أي عدد من ملفات PPTX/DOCX/XLSX/PDF معاً؛ تُسمّى الصور بسابقة اسم المستند ويظهر اسمه على كل بطاقة.
- «فحص المكرر» يقارن كل الصور عبر المستندات ويُبقي الأعلى جودة (الشعار المتكرر في 40 عرضاً = مجموعة واحدة).
- خيار «إضافة الملفات الجديدة إلى المعرض» لتراكم الدفعات، وخيار تصدير ZIP في مجلدات حسب المستند.

### الأسماء المقترحة (محلياً بالكامل)
يقرأ البرنامج ما كتبه مؤلف المستند حول الصورة: تعليقها («شكل 2: …» / «Figure 2 : …»)، نصها البديل (بعد تجاهل الأسماء الآلية مثل «Image 7»)، وعنوان الشريحة أو أقرب عنوان قسم في Word. تظهر 💡 على البطاقة (اضغط لتطبيقها) أو زر «💡 اقتراح الأسماء» للمحدد كله مع «تراجع». القالب من الإعدادات: `{loc}_{text}`. الصورة التي سبق حفظها في المكتبة يُقترح اسمها المحفوظ أولاً (ذاكرة الأسماء). لا يُحلَّل محتوى الصورة نفسه (ذلك في إصدار Pro لاحقاً).

### المكتبة المحلية 📚
IndexedDB داخل التطبيق، لا شبكة. تحفظ لكل صورة: البصمة، مصغّرة، الاسم، وكل ظهور (مستند + موضع + عنوان/تعليق/alt). الدمج تلقائي بالتشابه البصري. الافتراضي فهرس فقط؛ فعّل «نسخة كاملة» لحفظ الصورة نفسها (تُحفظ دائماً للصور المعدَّلة). بحث عربي/فرنسي مطبَّع (تشكيل، همزات، ة/ه، accents). الصور المصدَّرة تُضاف تلقائياً بأسمائها النهائية (قابل للإيقاف). في سطح المكتب: «📂 فتح المستند» يعيد قراءة الملف من مساره المحفوظ.

### الهوية البصرية
مطابقة لتطبيق «السبورة التفاعلية» تمهيداً لدمجهما: نيلي `#4f46e5` + رمادي مزرق (Slate)، خط **Cairo** (رخصة OFL، مضمَّن محلياً في `dist/fonts` ومشفَّر داخل `standalone.html`)، لوحات زجاجية بزوايا 1rem، أيقونات خطية بسمك 2.2. الوضع الداكن إضافة خاصة بهذا التطبيق مبنية على الألوان نفسها. القيم كلها متغيّرات CSS في أول `src/ui/style.css`.

## نسخة محمية (تشويش خفيف)
- للتطوير والتجربة: `npm run dist:win` (كود مقروء بعد الضغط).
- للتوزيع: `npm run dist:win:protected` (أو `npm run build:protected` لبناء `dist/` فقط).
- ما يفعله: تشويش كودنا نحن (`src/**`) فقط: كل النصوص تُنقل إلى مصفوفة مشفّرة base64 ومبدّلة، وتُسمّى المتغيرات سداسياً. لا تسطيح لتدفق التحكم ولا كود ميت ولا حماية من التنقيح، فلا أثر محسوس على الأداء (الحجم +2%). pdf.js وJSZip تُترك كما هي.
- هو يرفع كلفة قراءة الكود ولا يمنع استخراجه تماماً، وملف ZIP المصدري يبقى مقروءاً، فلا توزّعه إن أردت إخفاء المصدر.
- للتراجع: ابنِ بالأمر العادي `dist:win`.

## اللغة (عربي ⇄ فرنسي)
- زر الكرة الأرضية في الشريط العلوي يبدّل الواجهة كلها (النصوص والاتجاه RTL/LTR وقوائم سطح المكتب وشاشة الترحيب)، والاختيار محفوظ.
- العربية هي المفتاح الأصلي للنصوص؛ القاموس الفرنسي في `src/ui/i18n.js` (`FR`). لإضافة نص جديد: اكتبه بالعربية ثم أضف ترجمته إلى `FR`. اختبار الوحدة يفشل إن بقي نص عربي بلا ترجمة.
- الاسم في الفرنسية: Khalid Faouzi.

## التصدير المتقدّم («تصدير…»)
- **منظّم + CSV:** مجلد لكل مستند، وملف `index.csv` (UTF-8 مع BOM ليفتح في Excel بالعربية) فيه: المستند والمواضع والعنوان والتعليق والنص البديل والأبعاد والحجم والفئة.
- **للسبورة (موسوعة):** ZIP بصيغة `wb-encyclopedia` v1 يستورده برنامج السبورة من «📥 استيراد الموسوعة»، مع حقل «المادة». لا يوجد أي اتصال بين البرنامجين، الأمر مجرد ملف. الصيغ غير المدعومة في السبورة تُحوَّل إلى PNG، والصور فوق 15MB إلى JPEG.

## PDF
- تُستخرج الصور المضمّنة صفحةً صفحة (pdf.js محلي مضمَّن، بلا اتصال). الصورة المكررة في عدة صفحات = بطاقة واحدة تسرد صفحاتها («صفحات 1، 2، 5»).
- الصورة التي تغطي ≥ 80% من الصفحة (مسح ضوئي/خلفية) تأخذ شارة «صفحة كاملة»، ويمكن إخفاؤها من قائمة العرض دون حذفها.
- التدوير والقلب يُقرآن من مصفوفة التحويل؛ التعليق من النص أسفل الصورة (أو فوقها) والعنوان من أكبر خط في الصفحة.
- **المسح الضوئي:** الصفحات الممسوحة بالأبيض والأسود تُستخرج (صور 1-bit، وأقنعة ImageMask، وCCITT/JBIG2، وJPEG2000)؛ مفكّكاتها مضمَّنة داخل عامل pdf.js فلا يُحمَّل شيء من خارج التطبيق.
- **الجودة:** صور JPEG تُستخرج بايتاتها الأصلية كما في الملف (بلا إعادة ترميز) ما لم يلزم قص أو تدوير أو قلب أو كانت لها شفافية؛ وغيرها يُعاد ترميزه (PNG للشفافية والرسوم).
- حدود معروفة: PDF المحمي بكلمة مرور غير مدعوم، وأقنعة 1-bit المضمّنة داخل المحتوى مباشرة (Inline) تُتخطّى.

## الاستخدام السريع
افتح `dist/standalone.html` في أي متصفح حديث (ملف واحد، يعمل دون إنترنت).

## التطوير
```
npm install
npm run build     # ← dist/index.html + app.js + style.css + standalone.html (JSZip مضمّن)
npm test          # 20 اختبار وحدة (المنطق + المستخرجات)
npm run e2e       # اختبار شامل في Chromium (يتطلب python3 + Pillow + playwright)
```

## البنية
```
src/core/            منطق نقي بلا DOM (يُختبر في Node ويعمل داخل Worker)
  hash.js            dHash + تشابه + تجميع Union-Find
  geometry.js        قص الهوامش + srcRect
  xml.js             قراءة rels وblipFill وVML
  imaging.js         خط معالجة الصورة (Canvas/OffscreenCanvas)
  loc.js             مواضع الصور (شريحة / موضع / ترويسة / تذييل / حاشية)
  worker.js          نقطة دخول الـ Web Worker
  extractors/        pptx.js · docx.js · xlsx.js · pdf.js · common.js · index.js (السجل)
src/ui/              الواجهة (app.js, pool.js, style.css, index.template.html)
build.mjs            سكربت البناء (esbuild)
tests/ · e2e/        الاختبارات
```

## إضافة صيغة جديدة
اكتب كائناً `{ id, label, exts, scan(zip, opts) }` يعيد `{ entries, unsupported }` (انظر `extractors/docx.js`)، ثم سجّله في `extractors/index.js`.

## تطبيق سطح المكتب (Electron)
```
npm run start       # تشغيل البرنامج كنافذة سطح مكتب
npm run dist:win    # يبني على Windows:  release/Docs Asset Studio Setup x.y.z.exe (مثبّت) + ...-portable.exe (محمول)
npm run dist:dir    # نسخة غير مغلّفة في release/ للتجربة السريعة
```
- **بناء الـ `.exe` يتم على جهاز Windows** (يحتاج Node.js فقط). من Linux يفشل بناء المثبّت لأنه يتطلب Wine.
- فتح الملفات: من القائمة (Ctrl+O)، أو بسحب الملف على أيقونة البرنامج، أو بالنقر المزدوج إن ربطتَه بالامتداد؛ والنسخة الثانية من البرنامج تمرّر ملفها للنافذة المفتوحة.
- الأمان: عزل كامل للصفحة (`contextIsolation` + `sandbox`)، ولا وصول لنظام الملفات من الصفحة، وسياسة CSP تمنع أي اتصال خارجي.
- النسخة غير موقّعة رقمياً، لذا قد يعرض Windows تحذير SmartScreen عند أول تشغيل (يلزم شهادة توقيع لإزالته).
- الحجم بعد التغليف كبير (نحو 100MB للمثبّت) لأن Electron يضمّن Chromium.
- أيقونة `build/icon.ico` مؤقتة؛ استبدلها بأيقونتك (256×256 على الأقل).

## ملاحظات
- **Excel:** الموضع = الورقة + الخلية العليا اليسرى للصورة (مثل `الموازنة_B3`)، والسياق للأسماء المقترحة من نص الخلية فوقها أو يسارها. الصور «داخل الخلية» (Place in Cell) والرسوم البيانية لا تُستخرج كصور مواضع.
- **التدوير والقلب:** يُطبَّق ما كان في المستند (مضاعفات 90° فقط) وتظهر شارة «مُدار/مقلوب»؛ الزوايا الأخرى تُهمل. يتبع خيار «تطبيق القص والتدوير الأصليين».
- **القوالب:** صور التخطيطات والماسترات تأخذ مواضع `قالب n` / `ماستر n` ويُطبَّق عليها القص أيضاً.
- في DOCX لا توجد أرقام صفحات داخل الملف، فالموضع هو ترتيب ظهور الصورة في المتن (+ الترويسات/التذييلات/الحواشي).
- لم يُجرَّب البرنامج على Windows فعلياً (اختُبر الغلاف على Linux)، ولا على عروض/مستندات حقيقية واسعة.
